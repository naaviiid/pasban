# ربات تلگرام

با ربات تلگرام می‌توانید کاربران را بسازید، ویرایش کنید، وضعیت سرور را ببینید و گزارش رویدادها را دریافت کنید.

## راه‌اندازی

1. در [@BotFather](https://t.me/BotFather) دستور `/newbot` را بزنید و توکن ربات را بگیرید.
2. آیدی عددی حساب خودتان را از [@userinfobot](https://t.me/userinfobot) بگیرید.
3. در `.env`:
   ```ini
   TELEGRAM_API_TOKEN = 123456789:AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA
   TELEGRAM_ADMIN_ID = 987654321
   ```
   برای چند ادمین، آیدی‌ها را با کاما جدا کنید: `987654321, 123456789`
4. `pasban restart`
5. در ربات `/start` را بزنید.

::: tip سرور ایران
اگر سرور به تلگرام دسترسی ندارد، یک پروکسی تعیین کنید:
```ini
TELEGRAM_PROXY_URL = "socks5://127.0.0.1:1080"
```
:::

## کانال گزارش

برای دریافت گزارش رویدادها (ساخت، حذف، تمام شدن حجم و ...) در یک کانال:

1. ربات را ادمین کانال کنید.
2. آیدی عددی کانال را (که با `-100` شروع می‌شود) در `.env` بگذارید:
   ```ini
   TELEGRAM_LOGGER_CHANNEL_ID = -1001234567890
   ```

## امکانات منوی ادمین

| دکمه | کار |
| --- | --- |
| 🔁 System Info | وضعیت CPU، رم، ترافیک و تعداد کاربران |
| ♻️ Restart Xray | ری‌استارت هسته و نودها |
| 👥 Users | لیست کاربران، با امکان ویرایش، تمدید، ریست و حذف |
| ✏️ Edit All Users | عملیات گروهی: افزودن/کم کردن حجم و زمان، حذف منقضی‌ها و تمام‌حجم‌ها، افزودن/حذف اینباند |
| ➕ Create User | ساخت کاربر مرحله‌به‌مرحله |
| ➕ Create Bulk User | ساخت چند کاربر هم‌زمان |
| ➕ Create User From Template | ساخت کاربر از روی [قالب کاربر](#قالب-کاربر) |

## دستورها

| دستور | دسترسی | کار |
| --- | --- | --- |
| `/start` یا `/help` | ادمین | نمایش منوی اصلی |
| `/user <username>` | ادمین | نمایش اطلاعات یک کاربر |
| `/usage <username>` | همه | نمایش حجم و انقضای یک کاربر |

::: warning
دستور `/usage` برای همه فعال است. هر کسی نام کاربری را بداند، می‌تواند مصرف آن را ببیند. اگر این را نمی‌خواهید، نام‌های کاربری قابل حدس انتخاب نکنید.
:::

## قالب کاربر

قالب‌ها (User Templates) تنظیمات آماده مثل «۳۰ روز / ۵۰ گیگ» هستند. آن‌ها را با [API](./api) (`/api/user_template`) بسازید تا در ربات برای ساخت سریع کاربر قابل انتخاب باشند.

## اعلان به دیسکورد

```ini
DISCORD_WEBHOOK_URL = "https://discord.com/api/webhooks/xxxxxxx"
```

هر ادمین هم می‌تواند webhook دیسکورد اختصاصی داشته باشد:

```bash
pasban cli admin create -u admin2 -dc "https://discord.com/api/webhooks/..."
```
