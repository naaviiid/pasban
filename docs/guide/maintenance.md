# آپدیت، حذف و رفع مشکل

## آپدیت

```bash
pasban update
```

این دستور آخرین سورس را از مخزن می‌گیرد، ایمیج را دوباره می‌سازد و سرویس را ری‌استارت می‌کند. مایگریشن‌های دیتابیس هنگام شروع کانتینر خودکار اجرا می‌شوند. قبل از آپدیت، [پشتیبان بگیرید](./backup).

در نصب دستی:

```bash
cd pasban
git pull
pip install -r requirements.txt
alembic upgrade head
sudo systemctl restart pasban
```

## حذف

```bash
pasban uninstall
```

اسکریپت جداگانه می‌پرسد که پوشه‌ی داده‌ها (`/var/lib/pasban`) هم حذف شود یا نه.

## رفع مشکلات رایج

### داشبورد باز نمی‌شود

1. وضعیت را ببینید: `pasban status`
2. لاگ‌ها را بررسی کنید: `pasban logs`
3. مطمئن شوید پورت باز است:
   ```bash
   ss -tlnp | grep 8000
   ```
4. فایروال را بررسی کنید:
   ```bash
   sudo ufw allow 8000/tcp
   ```
5. اگر در لاگ پیام «only be accessible through localhost» را می‌بینید، یعنی SSL تنظیم نشده و پاسبان فقط روی localhost گوش می‌دهد. [SSL را تنظیم کنید](./ssl) یا موقتاً با SSH tunnel وصل شوید:
   ```bash
   ssh -L 8000:localhost:8000 root@SERVER_IP
   ```
   سپس `http://localhost:8000/dashboard/` را روی کامپیوتر خودتان باز کنید.

### Xray اجرا نمی‌شود

- معمولاً خطا در `xray_config.json` است. لاگ‌ها پیام دقیق Xray را نشان می‌دهند.
- پورت تکراری: دو اینباند نمی‌توانند روی یک پورت باشند (مگر با Fallback).
- مسیر گواهی‌ها باید داخل `/var/lib/pasban` باشد تا کانتینر به آن دسترسی داشته باشد.

### کاربر وصل نمی‌شود

- ساعت سرور را بررسی کنید (`timedatectl`). اختلاف زمان بیش از ۹۰ ثانیه در VMess باعث خطا می‌شود.
- آدرس و پورت لینک کاربر را در [تنظیمات هاست](./hosts) بررسی کنید.
- پورت اینباند را در فایروال باز کنید.

### رمز ادمین را فراموش کرده‌ام

```bash
pasban cli admin update -u admin
```
