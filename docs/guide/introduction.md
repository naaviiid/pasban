# معرفی

**پاسبان** یک پنل وب برای مدیریت کاربران پروکسی است که روی [Xray-core](https://github.com/XTLS/Xray-core) کار می‌کند. بک‌اند آن با Python (FastAPI) و داشبورد آن با React نوشته شده است و برای مدیریت صدها تا هزاران کاربر مناسب است.

پاسبان فورکی از پروژه‌ی متن‌باز [Marzban](https://github.com/Gozargah/Marzban) است و تحت مجوز AGPL-3.0 منتشر می‌شود.

## امکانات

- رابط کاربری وب و **REST API**
- پروتکل‌های **VMess**، **VLESS**، **Trojan** و **Shadowsocks**
- چند پروتکل برای هر کاربر و چند کاربر روی هر اینباند
- پشتیبانی از **TLS** و **REALITY** و Fallback
- **محدودیت حجم** و **تاریخ انقضا**، و ریست دوره‌ای حجم (روزانه، هفتگی، ماهانه، سالانه)
- حالت **On-Hold**: زمان کاربر از اولین اتصال شروع می‌شود
- **لینک سابسکریپشن** با تشخیص خودکار نرم‌افزار کاربر، و ساخت لینک اشتراک‌گذاری و QR code
- **چند سرور** با نودها
- مانیتورینگ منابع سرور و مصرف ترافیک کاربران و نودها
- **ربات تلگرام**، اعلان در دیسکورد و **Webhook**
- **CLI** داخلی
- چند ادمین: ادمین sudo همه چیز را می‌بیند، ادمین معمولی فقط کاربرانی که خودش ساخته

## مفاهیم اصلی

| مفهوم | توضیح |
| --- | --- |
| **هسته (Core)** | برنامه‌ی Xray که ترافیک را جابه‌جا می‌کند. پاسبان کانفیگ آن را می‌سازد و کاربران را به آن اضافه یا حذف می‌کند. |
| **اینباند (Inbound)** | پورت و پروتکلی که Xray روی آن گوش می‌دهد. در فایل `xray_config.json` تعریف می‌شود. |
| **هاست (Host)** | آدرس و تنظیماتی که در لینک کاربر قرار می‌گیرد (دامنه، پورت، SNI و ...). هر اینباند می‌تواند چند هاست داشته باشد. |
| **نود (Node)** | سرور دیگری که Xray را اجرا می‌کند و پاسبان کاربران را روی آن هم فعال می‌کند. |
| **ادمین** | حسابی که وارد پنل می‌شود. ادمین sudo دسترسی کامل دارد. |

## مسیر پیشنهادی

1. [نصب](./installation) پاسبان روی سرور
2. ساخت ادمین و ورود به داشبورد
3. تعریف اینباندها در [کانفیگ Xray](./xray-config)
4. تنظیم دامنه و [SSL](./ssl) و [هاست‌ها](./hosts)
5. ساخت کاربر و ارسال [لینک سابسکریپشن](./subscription)
