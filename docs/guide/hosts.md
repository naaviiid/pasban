# تنظیمات هاست

هاست تعیین می‌کند **چه آدرس و تنظیماتی در لینک کاربر** قرار بگیرد. هر اینباند می‌تواند چند هاست داشته باشد و کاربر برای هر هاست یک لینک جداگانه دریافت می‌کند. مثلاً یک اینباند با دو هاست: یکی آدرس مستقیم سرور و یکی آدرس CDN.

مسیر در داشبورد: منوی بالا ← **Host Settings**

## فیلدها

| فیلد | توضیح |
| --- | --- |
| **Remark** | نام کانفیگ در نرم‌افزار کاربر. می‌توانید از [متغیرها](#متغیرها) استفاده کنید |
| **Address** | دامنه یا IP که کاربر به آن وصل می‌شود |
| **Port** | پورت لینک. اگر خالی باشد، پورت اینباند استفاده می‌شود |
| **SNI** | نام سرور برای TLS/REALITY |
| **Host** | هدر Host (برای WebSocket، HTTP و ...) |
| **Path** | مسیر WebSocket/HTTP یا serviceName در gRPC |
| **Security** | `inbound_default` (مثل اینباند)، `none` یا `tls` |
| **ALPN** | مثلاً `h2` یا `http/1.1` |
| **Fingerprint** | اثر انگشت TLS، مثلاً `chrome` |
| **Allow insecure** | قبول گواهی نامعتبر در کلاینت |
| **Mux** | فعال کردن Mux در کانفیگ JSON |
| **Fragment** | تنظیم fragment در کانفیگ JSON |
| **Noise** | تنظیم noise در کانفیگ JSON |
| **Random User-Agent** | User-Agent تصادفی برای اتصال‌های HTTP |
| **Use SNI as host** | مقدار SNI به‌عنوان Host هم استفاده شود |
| **Disabled** | این هاست در لینک‌ها قرار نگیرد |

::: tip
تنظیمات Mux، Fragment و Noise فقط در کانفیگ‌های JSON اعمال می‌شوند (متغیرهای `USE_CUSTOM_JSON_*` در [تنظیمات](./configuration#سابسکریپشن)).
:::

## متغیرها

در **Remark** و **Address** می‌توانید از این متغیرها استفاده کنید:

| متغیر | مقدار |
| --- | --- |
| `{SERVER_IP}` | IPv4 سرور |
| `{SERVER_IPV6}` | IPv6 سرور |
| `{USERNAME}` | نام کاربری |
| `{DATA_USAGE}` | حجم مصرف شده |
| `{DATA_LIMIT}` | حجم کل (`∞` اگر نامحدود) |
| `{DATA_LEFT}` | حجم باقی‌مانده |
| `{DAYS_LEFT}` | روزهای باقی‌مانده |
| `{TIME_LEFT}` | زمان باقی‌مانده |
| `{EXPIRE_DATE}` | تاریخ انقضا (میلادی) |
| `{JALALI_EXPIRE_DATE}` | تاریخ انقضا (شمسی) |
| `{STATUS_EMOJI}` | ایموجی وضعیت کاربر |
| `{STATUS_TEXT}` | متن وضعیت کاربر |
| `{PROTOCOL}` | پروتکل (vless، vmess، ...) |
| `{TRANSPORT}` | نوع انتقال (tcp، ws، grpc، ...) |

مثال Remark:

```
🇩🇪 {USERNAME} | {DATA_LEFT} | {DAYS_LEFT} روز
```

### چند آدرس و زیردامنه‌ی تصادفی

- در **Address**، **SNI** و **Host** می‌توانید چند مقدار را با کاما جدا کنید. هر بار یکی به‌صورت تصادفی انتخاب می‌شود.
- علامت `*` با یک رشته‌ی تصادفی جایگزین می‌شود. مثلاً `*.example.com` (به شرط تنظیم wildcard DNS).

## یک هاست برای اطلاع‌رسانی

یک هاست با آدرس نامعتبر (مثلاً `0.0.0.0`) و Remark حاوی اطلاعات کاربر بسازید تا کاربر حجم و زمان باقی‌مانده را در لیست کانفیگ‌هایش ببیند:

```
📊 {DATA_LEFT} remaining | ⏳ {DAYS_LEFT} days
```
