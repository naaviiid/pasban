# Pasban

Pasban is a proxy user management panel powered by [Xray-core](https://github.com/XTLS/Xray-core), with a web dashboard, REST API, Telegram bot and CLI. It is a fork of [Marzban](https://github.com/Gozargah/Marzban) and is released under AGPL-3.0.

## Features

- **VMess**, **VLESS**, **Trojan** and **Shadowsocks**, with TLS and REALITY
- Multiple protocols per user, multiple users per inbound
- Data limits, expiry dates, periodic resets and on-hold accounts
- Subscription links that adapt to the client (v2rayN/NG, Clash, sing-box, Streisand, Happ, Outline)
- Multi-server support through nodes (compatible with Marzban-node)
- Telegram bot, Discord logging and webhooks
- Multiple admins (sudo and regular)
